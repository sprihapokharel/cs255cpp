- Standard Library Optional or Standard Library Variant
    - You don't know the data type to be returned: Lambda Functions

    - Standard Library Optional (std::optional)

    - Ex: Finding user with student ID of 111 (but they've graduated, no student exists with 111)
            - We want it to return an optional (failed returned error)
            - Optional is not a critical failure (not like a server failure, we don't want to crash out of the program)
            - "No user here, did you want 112?" -> prompting the user for another, something similar

    - Practicing "noexcept" to optimize code, improve performance (when we don't want an exception to be thrown during the process of it)
    - Ex again: We want to not fail when we do an add function

    - Standard Library Variant (std::variant)
        If you have multiple data types, not sure what the return type will be
